# Arc Node crates.io placeholders

This branch contains placeholder packages for Arc Node crate names intended for
crates.io publishing.

The real Arc Node source is developed in the public repository:

https://github.com/circlefin/arc-node

Do not depend on these placeholder releases for runtime functionality. They
exist to establish the crates.io package names while the publishable Arc package
graph is prepared.
